# Kıbrıs Cumhuriyeti Temsilciler Meclisi Konuşma Arşivi (Türkçe)

Kıbrıs Cumhuriyeti Temsilciler Meclisi (`parliament.cy`) resmî tutanakları üzerinde **sunucusuz (DuckDB-WASM + HTTP Range Parquet)** çalışan, Kıbrıs Türk okuyucuların tamamını **Türkçe** okuyup arayabileceği konuşmacı bazlı arşiv uygulaması (`kktcmeclisarsivi.org` formatında).

* **Orijinal Türkçe konuşmalar** (1960–1963 iki toplumlu dönem Türk milletvekilleri) zabıtlardaki özgün imlasıyla kelimesi kelimesine korunur.
* **Yunanca konuşmalar** sadık Türkçe çevirisiyle aranabilir ve okunabilir; her konuşmada tek tıkla **Orijinal Yunanca** zabıt metni karşılaştırmalı olarak görüntülenebilir.
